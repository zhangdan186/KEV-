`data/CISA_KEV_2026-07-29.json`和完整流水线生成的`outputs/`，不得使用测试夹具或手工
修改的结果数字。

当前`01`至`07`已在本机手动上传课程JSON后全部拍摄完成，分辨率为1440×900；另补充
`06b-ml-cluster-details.png`展示完整二维散点图和聚类摘要。`00-upload-state.png`仅保留为
应用启动与上传前状态记录，不建议作为“加载成功”截图提交。

## 推荐演示条件

优先复用正式查询案例，保证结果非空且数字可核对：

- 案例1：启用日期范围`2022-01-01`至`2022-12-31`，厂商输入`Microsoft`，状态选择
  `Known`，预期51条；
- 案例2：厂商输入`Microsoft`，CWE输入`CWE-119`，预期34条；
- 案例3：日期范围`2022-01-01`至`2022-12-31`，状态选择`Unknown`，CWE输入
  `CWE-119`，预期60条。

截图`02`建议使用案例2并选择“CWE Top 20”；截图`03`和`04`可沿用同一筛选结果，减少
答辩切换时间。

## 拍摄顺序

1. 先运行`.\.venv\Scripts\python.exe main.py`生成正式输出；
2. 运行`.\.venv\Scripts\python.exe -m streamlit run app.py`；
3. 上传课程JSON，确认元数据后拍摄`01`；
4. 设置案例2条件并依次拍摄`02`至`05`；
5. 切换机器学习和数据校验标签页，拍摄`06`和`07`；
6. 检查截图没有浏览器下载浮层、系统通知、账号信息或本地敏感路径。

## 版式要求

- 使用同一浏览器窗口和缩放比例，建议1440×900或更高分辨率；
- 保留页面标题、当前标签和必要的侧栏条件，裁掉无关浏览器区域；
- 正文和指标清晰可读，不拉伸、不二次压缩；
- 文件名保持两位数字前缀，报告和PPT按文件名引用；
- 如界面或正式数字变更，重新运行流水线并重拍全部受影响截图。
