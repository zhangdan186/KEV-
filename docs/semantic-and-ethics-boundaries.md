# 语义与结论边界

报告、图表标题、PPT和答辩必须遵守：

- 月度数量称为“加入KEV目录的记录数”，不得称“漏洞披露数”“攻击数”；
- `deadline_days`称为“目录行动窗口”，不得称“实际修复耗时”；
- `Known/Unknown`称“已确认/尚未确认”，不得称“勒索/非勒索漏洞”；
- 厂商数量和集中度仅反映目录标签分布，不代表市场份额、安全质量或攻击概率；
- CWE多标签比例可超过100%，不得强行归一为互斥类别；
- KMeans结果称“文本特征聚类”，不得称“官方漏洞分类”或预测结果；
- 不使用本地快照外的数据补充实际攻击次数或严重度结论，除非报告单独标明外部研究且教师允许。
