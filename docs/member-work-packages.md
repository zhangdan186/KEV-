# 三人工作包

## 成员一：数据底座、集成与质量

- Loader、Validator、Cleaner、Exporter、Pipeline；
- 公共字段和模型；
- 契约与单元测试框架；
- README、运行环境、最终整合；
- 报告总编与答辩开场/总结。

## 成员二：统计分析与机器学习

- 时间、期限、勒索状态；
- 厂商、产品、CR5/CR10/HHI；
- 相关静态与交互图表；
- TF-IDF+KMeans扩展；
- 对应报告与PPT分析页。

## 成员三：CWE、查询与GUI

- CWE展开、总体及分组统计；
- 指定`filter_kev`及三组查询；
- Streamlit GUI；
- 图表动态展示、详情和导出；
- PPT视觉整合与现场演示。

## 共同验收

每名成员必须：

- 编写自己模块测试；
- 提供报告文字、图表和结论限制；
- 能解释自己模块公式和边界；
- 参与至少两次模拟答辩；
- 复核另一名成员的一个模块。
