# 报告、PPT与答辩交付计划

## 1. 作业报告建议目录

1. 项目背景与任务目标
2. 数据集与字段语义
3. 需求分析与评分覆盖
4. 系统架构与模块设计
5. JSON读取、校验和清洗
6. 时间分布分析
7. 处置期限分析
8. 勒索软件确认状态分析
9. 厂商、产品与集中度分析
10. CWE多标签分析
11. 组合查询函数
12. GUI设计与实现
13. 机器学习扩展
14. 系统测试与可复现性
15. 结果讨论、限制与伦理边界
16. 总结与成员分工
17. 参考资料

每个技术章节固定采用：要求→方法→接口/公式→结果表→图表→解释→正确性校验→局限。

## 2. PPT建议14页

1. 封面
2. 背景与任务
3. 评分覆盖与完成度
4. 技术路线和架构
5. 数据结构、校验与清洗
6. 时间与期限
7. 勒索状态
8. 厂商产品与集中度
9. CWE多标签
10. 组合查询
11. GUI架构与界面
12. 机器学习扩展
13. 现场演示
14. 结论、局限与分工

## 3. 数值一致性

- 报告和PPT不得手工抄算；
- 最终数值统一从`outputs/`读取；
- 每个图表记录其数据源文件名；
- 提交前运行`docs/checklists/final-delivery-checklist.md`。

## 4. 答辩演示固定流程

1. 启动GUI；
2. 加载原始JSON；
3. 展示元数据和校验通过；
4. 使用一组已验证的多条件查询；
5. 展示动态月度、厂商和CWE图；
6. 选择一条CVE查看详情；
7. 导出CSV/PNG；
8. 展示机器学习聚类页；
9. 回到总结页。

现场演示必须准备离线方案和预生成截图，避免环境故障导致无内容可讲。
