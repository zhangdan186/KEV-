# 测试与质量门槛

## 1. 测试层次

1. 契约测试：字段、签名、输出注册表、冻结哈希；
2. 单元测试：每个函数的正常、边界和异常输入；
3. 集成测试：`load→validate→prepare→analyze→export`；
4. 黄金数据测试：冻结快照的关键计数；
5. GUI冒烟测试：加载、筛选、重置、详情、导出；
6. 交付一致性测试：代码输出、报告数字和PPT数字一致。

## 2. 必测用例

### Loader/Validator

- 文件不存在；
- 非法JSON；
- 缺少顶层字段；
- count不一致；
- 记录字段缺失；
- CVE重复/格式错误；
- 日期非法/顺序错误；
- 非法勒索状态；
- cwes非列表/成员非法；
- 171空CWE等黄金计数。

### Cleaner

- 原始字段不被改变；
- 只去首尾空格；
- 日期类型正确；
- deadline_days正确且非负；
- 输入DataFrame不被原地修改。

### 分析

- 月序列完整且连续；
- 不完整年份标记；
- 各类计数与总数守恒；
- share之和约等于1；
- cumulative_share最后约等于1；
- CR5<=CR10<=1；
- HHI在(0,1]；
- Top30稳定排序；
- CWE唯一关系及正确分母。

### Query

- 无条件返回全部并按规则排序；
- 单边日期；
- 闭区间边界；
- start>end异常；
- 厂商大小写与字面匹配；
- 非法状态；
- CWE大小写归一化、精确匹配、非法格式；
- 多条件AND；
- 空结果结构；
- 原DataFrame不变。

## 3. 质量门槛

### Gate 0：契约冻结

- `verify_freeze.py`通过；
- 契约测试全部通过；
- 三人签字确认。

### Gate 1：必做80分

- 四大模块全部输出；
- 所有关键单元测试通过；
- 无FATAL/ERROR校验项；
- 输出注册表校验通过。

### Gate 2：GUI 14分

- 原始JSON加载；
- 日期、厂商、产品、Known/Unknown、CWE筛选；
- 重置；
- 至少两张动态图；
- 表格、详情；
- CSV和PNG导出。

### Gate 3：机器学习6分

- 固定随机种子；
- 多个K比较；
- 轮廓系数或合理指标；
- 关键词、代表记录、Known比例、二维图；
- 报告明确无监督聚类局限。

### Gate 4：最终交付

- 新环境按README可复现；
- 报告和PPT所有数值来自正式输出；
- 演示脚本完整；
- 压缩包无绝对路径、缓存、虚拟环境和无关大文件。

## 4. 覆盖率建议

- 核心Loader/Validator/Cleaner/Query：行覆盖率至少90%；
- 必做分析模块：至少80%；
- 整体核心代码：至少80%；
- GUI展示层不强制行覆盖率，但必须有冒烟清单。
